Guía Rápida: Ventana de Cuentas

En esta ventana puedes gestionar todas tus cuentas bancarias de forma centralizada.

Acciones Disponibles

  • Visualizar: Revisa la lista con el ID, descripción, saldo y tipo de cada cuenta.
  • Nueva Cuenta: Haz clic en el botón "New" para generar una cuenta automáticamente.
  • Editar: Puedes modificar la Descripción o el Tipo haciendo doble clic sobre la celda en la tabla.
  • Ver Movimientos: Selecciona una cuenta y pulsa "Continue" para ver sus transacciones detalladas.
  • Eliminar: Selecciona una cuenta y pulsa "Delete" (solo si no tiene movimientos asociados).

Navegación

Usa el botón "Exit" para cerrar la sesión o utiliza el Menú superior para obtener ayuda rápida o información del sistema.
